# Attestation Document Format

Technical specification of Nitro Enclave attestation documents.

## Overview

Attestation documents are cryptographically signed proofs generated by the Nitro Secure Module (NSM) hardware. They prove what code is running inside an enclave.

## Fetching attestations

```bash
curl https://your-app.caution.app:5000/attestation?nonce=<base64-nonce>
```

The response is a base64-encoded COSE_Sign1 structure.

## Document structure

### COSE_Sign1 format

Attestation documents use [COSE_Sign1](https://datatracker.ietf.org/doc/html/rfc8152) (CBOR Object Signing and Encryption):

```
COSE_Sign1 = [
    protected_header,    # Algorithm identifier
    unprotected_header,  # Empty
    payload,             # CBOR-encoded attestation data
    signature            # ECDSA P-384 signature
]
```

### Payload structure

The payload is CBOR-encoded with these fields:

| Field | Type | Description |
|-------|------|-------------|
| `module_id` | string | Enclave module identifier |
| `timestamp` | integer | Unix timestamp (milliseconds) |
| `digest` | string | Hash algorithm used ("SHA384") |
| `pcrs` | map | PCR values (index → bytes) |
| `certificate` | bytes | NSM certificate (DER) |
| `cabundle` | array | CA certificate chain |
| `public_key` | bytes | Optional enclave public key |
| `user_data` | bytes | Optional user-provided data |
| `nonce` | bytes | Client-provided nonce |

### PCR map

```cbor
pcrs: {
    0: h'abc123...',  # 48 bytes (SHA-384)
    1: h'def456...',  # 48 bytes
    2: h'789abc...',  # 48 bytes
    ...
}
```

## Certificate chain

The certificate chain validates back to the AWS Nitro Root CA:

```
NSM Certificate (signs attestation)
       ↓
Intermediate CA
       ↓
AWS Nitro Root CA (trust anchor)
```

### AWS Nitro Root CA

The root certificate is published by AWS and embedded in verification tools:

- Subject: `CN=aws.nitro-enclaves`
- Algorithm: ECDSA P-384
- [AWS documentation](https://docs.aws.amazon.com/enclaves/latest/user/verify-root.html)

## Verification process

### 1. Decode document

```python
import base64
import cbor2

raw = base64.b64decode(attestation_b64)
cose = cbor2.loads(raw)
```

### 2. Parse COSE_Sign1

```python
protected = cose[0]
payload = cbor2.loads(cose[2])
signature = cose[3]
```

### 3. Validate certificate chain

Verify the chain from NSM certificate to AWS root:

```python
# Extract certificates
nsm_cert = payload['certificate']
ca_bundle = payload['cabundle']

# Validate chain (using your crypto library)
verify_chain(nsm_cert, ca_bundle, AWS_NITRO_ROOT_CA)
```

### 4. Verify signature

```python
# Get public key from NSM certificate
public_key = extract_public_key(nsm_cert)

# Verify COSE_Sign1 signature
verify_ecdsa_p384(
    message=cose[0] + cose[2],  # protected + payload
    signature=signature,
    public_key=public_key
)
```

### 5. Validate nonce

```python
assert payload['nonce'] == expected_nonce
```

### 6. Compare PCRs

```python
assert payload['pcrs'][0] == expected_pcr0
assert payload['pcrs'][1] == expected_pcr1
assert payload['pcrs'][2] == expected_pcr2
```

## Debug mode detection

Debug enclaves have specific PCR values:

```python
DEBUG_PCR = bytes(48)  # All zeros

if payload['pcrs'][0] == DEBUG_PCR:
    print("WARNING: Enclave is in debug mode")
```

!!! warning
    Never trust attestations from debug mode enclaves in production.
