# Roadmap

What we're working on and where Caution is headed.

## Current focus

We're actively working on:

- **Improved build reproducibility** - Making it easier to achieve deterministic builds
- **Additional TEE support** - Expanding beyond AWS Nitro Enclaves
- **Developer experience** - Streamlining the deployment workflow

## Planned features

### Near term

- Custom domain support
- Log streaming improvements
- Enhanced attestation tooling

### Future

- Multi-region deployments
- Team collaboration features
- Additional cloud provider support

## Completed

- Passwordless authentication with FIDO2
- Git-based deployments
- Attestation verification
- End-to-end encrypted networking
