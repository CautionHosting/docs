## AGPL-3.0 (Open Source)

For open source projects, personal use, and non-commercial use, Caution is licensed under the [GNU Affero General Public License v3.0](https://www.gnu.org/licenses/agpl-3.0.html).

### What you can do

- Use, modify, and distribute the software freely
- Run Caution as a service
- Build applications on top of Caution

### What you must do

- Share **all source code** of any modified version
- Share **all code** that uses Caution as a library
- If running as a service, provide **complete source code** to your users

The AGPL includes the "network use" clause: if you run Caution as a hosted service, you must provide the complete source code to anyone who interacts with it over a network.

### Good for

- Open source projects that already share their code

### Not ideal for

- Businesses wanting to keep infrastructure proprietary
- Companies offering competing PaaS services
- Organizations with proprietary modifications

## FAQ

??? question "Do I need a commercial license?"

    **If you're comfortable sharing all your code** (infrastructure, deployment scripts, modifications), you can use AGPL-3.0.

    **If you want to keep any part private**, you need a commercial license.

    **If you're running Caution as a service for others**, you likely need a commercial license.

??? question "Can I deploy proprietary applications on Caution?"

    Yes. The applications you deploy *on* Caution remain yours with their own licenses. This license only covers Caution itself, not what you run on it.

??? question "I'm a non-profit or educational institution"

    Contact us. We offer special pricing for non-profits, educational institutions, and open source projects. Many qualify for free commercial licenses.

??? question "I want to contribute code"

    By contributing, you agree to license your contributions under both AGPL-3.0 and the commercial license. This allows us to offer both license options.
