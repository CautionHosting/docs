# Get involved

Caution is an open source project and we welcome contributions from the community. Whether you're fixing bugs, improving documentation, or proposing new features, your help is appreciated.

## Ways to contribute

- **Report bugs** - Help us improve by reporting issues you encounter
- **Improve documentation** - Fix typos, clarify explanations, or add examples
- **Submit code** - Fix bugs or implement new features
- **Join discussions** - Share ideas and help others in our community channels

## Community channels

- **Repository**: [codeberg.org/caution/platform](https://codeberg.org/caution/platform)
- **Issues**: [Report bugs and request features](https://codeberg.org/caution/platform/issues)

## Getting started

1. Read our [How we work](how-we-work.md) guide to understand our development process
2. Check out the [Code of conduct](code-of-conduct.md)
3. Find an issue to work on or report a new one
4. Submit a pull request

We look forward to your contributions!
